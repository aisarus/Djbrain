# Djbrain

Интерактивный 3D-интерфейс будущей цифровой когнитивной архитектуры.

## Что уже есть

- процедурная 3D-модель мозга на Three.js;
- отдельные функциональные регионы;
- клики и touch-взаимодействие через raycasting;
- вращение, масштабирование и сброс камеры;
- анимированные электрические импульсы между областями;
- информационная панель для каждой зоны;
- адаптивный интерфейс для desktop, tablet и mobile;
- готовая Vite-сборка для Vercel.

## Локальный запуск

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Деплой на Vercel

1. Импортировать репозиторий `aisarus/Djbrain` в Vercel.
2. Framework Preset: `Vite`.
3. Build command: `npm run build`.
4. Output directory: `dist`.
5. Нажать Deploy.

Vercel обычно определяет эти настройки автоматически.
